## 🧠 Introduction

**UIU CGPA Calculator** is a smart, interactive React + TypeScript app built for **United International University** students to:
- ⚡ Instantly calculate **CGPA & GPA**
- 📊 Track detailed **assessment performance**
- 🔁 Handle **course retakes**
- 🔮 Predict **projected results** for upcoming trimesters

It’s **fast**, **accurate**, and **student-focused** — built using **Vite**, **React**, and **TypeScript**, ensuring performance and scalability.

---

## ✨ Key Features

| Feature | Description |
|----------|--------------|
| 🎯 **CGPA & GPA Calculator** | Calculates trimester GPA and cumulative CGPA accurately using official UIU grading scale |
| 🔁 **Retake Support** | Adjusts GPA automatically when courses are retaken |
| 🧩 **Assessment Tracker** | Separate logic for **Theory** and **Lab** courses, with detailed internal assessments |
| 📈 **Projected Grades** | Predicts what GPA you need to reach your target CGPA |
| 🪶 **Beautiful UI + Animation** | Clean Tailwind-inspired layout with subtle fade-in animations |
| 💾 **Offline Ready** | Fully client-side — no server or login needed |

## 🧮 Formula Reference

\[
CGPA = \frac{\sum (Credit_i \times GradePoint_i)}{\sum Credit_i}
\]

**Official UIU Grading Scale**

| Grade | Point | Range (%) |
|-------|--------|-----------|
| A+ | 4.00 | 80%+ |
| A | 3.75 | 75–79% |
| A− | 3.50 | 70–74% |
| B+ | 3.25 | 65–69% |
| B | 3.00 | 60–64% |
| B− | 2.75 | 55–59% |
| C+ | 2.50 | 50–54% |
| C | 2.25 | 45–49% |
| D | 2.00 | 40–44% |
| F | 0.00 | <40% |
